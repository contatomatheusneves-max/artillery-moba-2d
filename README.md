# Artillery MOBA 2D

Protótipo experimental de jogo de artilharia 2D, inspirado no gênero de combate balístico com terreno destrutível.

## Jogar

Abra `index.html` no navegador. Quando o GitHub Pages estiver habilitado, o protótipo poderá ser acessado pela URL publicada em **Settings → Pages**.

## Versão atual: 0.2

- Três tipos de mapa e terreno destrutível
- Dois tanques, física balística e vento
- Movimentação com combustível por turno
- Três armas
- Combate contra CPU e dois jogadores locais
- Câmera e efeitos básicos

## Próximas decisões

Antes de alterar o combate, validar ritmo, armas e mecânicas com testes comparativos. O protótipo 3D foi descartado como direção principal.

## Publicação no GitHub Pages

1. Em **Settings → Pages**, selecione **Deploy from a branch**.
2. Escolha a branch `main`, pasta `/ (root)` e salve.
3. Aguarde a publicação e abra o endereço apresentado na página.

**Observação:** para usar Pages gratuitamente, o repositório deve estar público. O GitHub Pages é um host estático, não um servidor de multiplayer.
